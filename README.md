# Мегалюль

Одиночная игра по мотивам Tofu Drifter в сеттинге пранка про капитана Данилкина: верфь-платформа посреди океана, как нефтяная вышка,
с четырьмя комнатами на палубе. Цех варит удобрение, контора берёт заказы, танкер везёт цистерны по реке и дрифтует в поворотах.
Цель карьеры: накопить на «Питса 4 сыра Мазерати» (название пишется именно так). Это гигантская коробка пиццы с приоткрытой крышкой,
она встанет на вертолётной площадке у конторы.

Альбомный экран 16:9: на компьютере рамка занимает окно целиком, на телефоне игра играется в горизонтальной ориентации (в вертикальной просит повернуть).
Вкладки комнат стоят столбиком справа, камера смотрит на верфь чуть сбоку, чтобы выбранная комната была слева от панелей.

## Запустить

```bash
npm start               # http://localhost:3000
```

Игра работает и с диска, открытием `public/index.html`, сервер нужен только для раздачи файлов.

## Опубликовать на сервер

Новой игре не нужен ни Node, ни база: это статические файлы. Порядок:

```bash
npm run build                                   # собирает dist/: index.html, js/, vendor/, иконка, манифест; адреса скриптов со штампом версии
PUBLISH_TARGET=user@host:/var/www/megalul npm run deploy   # то же плюс заливка dist/ на сервер по rsync
```

Если rsync и ssh нет, папку `dist/` целиком заливают по FTP или через панель хостинга: лежать она должна в корне сайта.
На сервере её отдаёт любой веб-сервер: примеры в `deploy/Caddyfile` (HTTPS сам) и `deploy/nginx.conf`; скрипты можно кэшировать
надолго, потому что при каждой сборке их адреса меняются, а `index.html` кэшировать не нужно. `npm run build:legacy` добавляет в сборку
старую игру с озвучкой. Для Cloudflare Pages: `npm run cf:deploy` (собирает и заливает `dist/`).
Проверка перед публикацией: `npm test` прогоняет логику и сборку верфи в Node.

## Как играть

- **Верфь.** Вкладки внизу переключают комнаты, камера поворачивается к выбранной. Над вкладками плавающая панель действий комнаты.
  Контора: заказы, улучшение, дзен. Цех и склад: запасы и улучшение. Док: улучшение, магазин кораблей и трофея, доработки.
- **Заказ** требует N цистерн со склада и сдаётся по частям в портах по пути: пройдите у головы причала через синее кольцо.
  Большинство заказов по плечу текущему кораблю, остальные зовут купить побольше; заказ висит на доске 15 минут, потом его забирают другие.
  Промах мимо причала оставляет цистерны на борту, за них не платят. На финише оплата умножается на долю сданного и на состояние груза.
- **Заезд.** Корабль идёт сам и быстро, как гоночная машина: 54–66 м/с (195–240 км/ч) у базовых кораблей, темп заказа добавляет ещё до четверти
  (сложные заказы быстрее, в карточке это метка «быстро»), двигатель даёт +3 м/с за ступень. Река раскроена под такую скорость: длинные прямые,
  широкие дуги, рейсы 2,4–5,4 км. В заносе ход почти не теряется: вектор скорости лишь догоняет курс с задержкой, угол заноса держится около 40°,
  а скорость остаётся на уровне 92–95% крейсерской, так что темп не падает. Скорость в км/ч видна под счётом дрифта;
  камера в альбомном экране ниже и ближе, как за машиной, и с ростом скорости расширяет угол обзора.
  Удерживайте левую или правую половину экрана, стрелки или A/D: на ходу это срывает корму в занос.
  Отпустили, и корпус ловит воду обратно. Очки за дрифт идут, пока есть угол и ход; множитель растёт с длиной серии и применяется в конце,
  удар о берег, камень или чужой борт закрывает серию без множителя и портит груз. Монеты по пути идут на счёт, звёзды дают опыт.
- **Опыт и уровни.** Опыт равен счёту дрифта плюс часть оплаты за груз. Уровень стоит 300 × уровень² опыта: квадратично, как в оригинале, но мягче.
  Уровни открывают улучшения комнат, деньги их оплачивают. Прогрессия быстрая: по автотесту все комнаты на максимуме примерно к 30-му заезду,
  а на трофей хватает после часа-полутора игры.
- **Трассы.** Янцзы с первого уровня конторы, Севморпуть со льдом со второго, Малакка с камнями с третьего, ночной Босфор с четвёртого,
  сложные трассы с пятого. Новый заказ на доске каждые полторы минуты, на пустой доске через полминуты.
- **Дзен.** Длинная река без груза, счёт идёт в опыт.
- **Верфь.** Платформа стоит в океане на четырёх опорах: вокруг вода до горизонта, буи, далёкая баржа. Каждая комната на первом уровне
  голая и неуютная (бетон, лужи, лампочка на проводе, ящик вместо стола), с каждым улучшением в ней появляется мебель, свет и уют,
  а в панели улучшения написано, что именно. Платформа в целом хорошеет по сумме уровней комнат: перила, шлюпка, фонари, флаг, гирлянда.
  Кран дока, слип к воде, факел цеха и контейнеры склада появляются на палубе с уровнями своих комнат.
- Сохранение в браузере, цех работает по часам и пока игра закрыта.

## Проверка без экрана

- `index.html#autotest`: фиксированный шаг по таймеру, автопилот у руля, заказы берутся сами, в консоль идёт строка состояния каждые три секунды.
- `index.html#photo`: два кадра в секунду в полном качестве, удобно снимать скриншоты в безэкранном Chrome без разогрева процессора.
  Добавка `&rooms=5&trophy=1&room=dock` показывает витрину: все комнаты на заданном уровне, трофей куплен, камера на выбранной комнате; такая карьера не сохраняется.
- `node tools/harness.mjs 30`: вся логика в Node без браузера, 30 виртуальных минут автотеста за пару секунд (заглушки DOM и рендерера, виртуальное время,
  автопилот у руля); печатает итог карьеры и каждый заезд. `SWEEP=1` дополнительно собирает верфь на всех уровнях комнат.
- `node tools/shot.mjs кадр.png "#photo&rooms=3&room=dock"`: скриншот через DevTools-протокол безэкранного Chrome (страница, пара секунд, кадр, закрыть);
  пятый аргумент — выражение JS, которое выполнить перед кадром, например открыть панель или прокрутить заезд.
