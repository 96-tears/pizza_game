# Публикация отдельной ветки

Ветка `codex/mobile-pages` содержит исправления игры и готовый сайт в `docs/`.
Основная ветка `main` не изменяется.

Владельцу репозитория:
1. Открыть Settings → Pages. Если сайт уже настроен, не переключать его без согласования: Pages настраивается на весь репозиторий.
2. Если Pages ещё не включён: Source → Deploy from a branch, ветка `codex/mobile-pages`, папка `/docs`, Save.
3. Дождаться публикации и открыть адрес, показанный GitHub.

Приватность репозитория менять не нужно. Если GitHub требует другой тариф для Pages в приватном репозитории, текущая публикация https://vlad1slavs.github.io/megalul-game/ продолжает работать.

Обновление: выполнить `npm test`, затем `npm run build`, заменить содержимое `docs/` содержимым `dist/`, сохранив `.nojekyll`, и отправить изменения только в эту ветку.

Готовая сборка включает внешнюю Google-форму, предложение установки на главный экран и исправления мобильного интерфейса. Backend и база данных для неё не нужны.
